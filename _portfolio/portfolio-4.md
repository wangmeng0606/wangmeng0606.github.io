Ion pairing measured spectroscopically needs to be translated into a form that's usable for predicting solution behavior—activity coefficients and speciation. This project incorporates ion-pairing effects into an extended Pitzer model, connecting the molecular-scale characterization from the ion-pairing work above directly to a thermodynamic framework for predicting activity coefficients in electrolyte solutions.
